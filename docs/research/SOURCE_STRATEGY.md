# 来源策略

## 来源层级

| 层级 | 类型                                             | 用途                                   | 默认编辑状态                        |
| ---- | ------------------------------------------------ | -------------------------------------- | ----------------------------------- |
| A    | 同时代诏令、制词、奏议、文集、墓志及官修编年材料 | 任命动作、原文、到任与处分的直接证据   | reviewed 或 verified                |
| B    | 后修正史、会要、典章汇编                         | 制度定义、官名沿革、人物传记和交叉核对 | reviewed；需考虑成书时代            |
| C    | 现代专著和同行评议论文                           | 制度解释、争议和研究史                 | reviewed；版权仅保存必要短引文      |
| D    | 权威结构化数据库                                 | 人物、地点、任官和外部 ID 对齐线索     | provisional，回查史料后晋级         |
| E    | 数字转录、通俗参考                               | 检索入口和文本定位线索                 | provisional；不得单独支撑高风险结论 |

`verified` 表示项目已按录入规范核查定位与转录，不表示学界不存在争议。

## 首批研究入口

- 《宋史·职官志》卷 161—172：制度骨架和官名职掌；
- 《宋史》卷 338《苏轼传》：已穷尽枚举该数字转录中的任官／身份语句，用作可公开复核的次级覆盖锚点；
- 《续资治通鉴长编》：同期除授、制度变化与政治事件交叉核对；
- 《宋会要辑稿·职官》与《宋大诏令集》：制度条文、诏令和任命文书；
- 苏轼文集中的谢表、奏议和书信：本人同时代记录；
- 孔凡礼《苏轼年谱》（中华书局1998年三册本）：完整官履 coverage 分母和编年锚点；当前仅核书目与目录范围，因无合法全文访问而标为 blocked，不从未授权转载本摘录史实；
- 龚延明《宋代官制辞典》、邓小南《宋代文官选任制度诸层面》等专门研究：白话解释与争议背景。

## 数字资源使用规则

- CTP、Wikisource 等 URL 记录为具体数字 manifestation/item，不冒充纸本版本。
- CBDB 和 CHGIS 是对齐与线索，不是唯一真相；保存 authority、external ID、核查日期和 match status。
- 不从搜索摘要录入断言；必须打开来源或可定位转录。
- 现代版权材料不整本保存；只录书目、必要短引文、结构化研究结论和定位。
- 批量导入前记录授权、许可、下载日期、数据版本和引用要求。
