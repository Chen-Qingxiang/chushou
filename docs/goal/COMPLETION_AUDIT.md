# Goal 完成审计

审计日期：2026-07-13
审计对象：`0.3.1-research.1`，分支 `codex/goal-chushou-system`

## 结论

本地产品、数据、研究文档和质量门槛已经达到可部署研究预览版的完成条件。系统没有把学术缺口包装成“完整苏轼生涯”：孔凡礼《苏轼年谱》的逐条 coverage 分母因合法全文不可得而保持 external blocker；GitHub Pages 目标地址尚未发布，因为推送／合并属于需要用户授权的外部动作。

除这两项外，本审计没有保留可在本地完成而未完成的产品或工程缺口。品秩全表、更多人物切片、通用概率任官规则和真实辅助技术人工审计是后续研究扩展，不改变当前 release 的诚实边界。

状态含义：`PASS` 为本地可复现满足；`SCOPED PASS` 为功能可用且缺证范围在数据和界面明示；`EXTERNAL BLOCKER` 为必须取得受版权材料或远端授权才能继续。

## 同一事实模型检查

- `data/curated/` 是唯一人工编辑权威源；`data/generated/`、站点数据、搜索索引、报告和下载均由同一确定性生成器产生。
- UI 不维护第二套解码规则：`apps/web` 调用 `packages/domain/src/decoder.ts`。
- 多维轨迹不维护硬编码分数：`packages/domain/src/careerSignals.ts` 从 appointment、usage、institution、rank 和 service 投影分类信号。
- 官名、机构、任命、来源和比较页面只读取生成的 `SiteProjection`。
